# Shopping Mall Network System

Shopping Mall Network System is a networking project designed in Cisco Packet Tracer. The project simulates a multi-device network environment for a shopping mall and demonstrates basic network design, IP addressing, and device configuration.

## Technologies
- Cisco Packet Tracer

## Features
- Multi-device network topology
- Router and switch configuration
- End device connectivity
- Inter-device communication
- IP addressing implementation
- Fundamental networking design principles

## Project Structure
- Packet Tracer project file (.pkt)
- Network diagrams
- Documentation

## Run Locally
Open the `.pkt` file in Cisco Packet Tracer to view the network topology and test connectivity.
